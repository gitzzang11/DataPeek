# DataPeek {VERSION}

첫 공개 버전입니다.

주요 기능:

- 프리티 실제 데이터 사용량 조회
- Google 간편 로그인
- 잔여/사용/전체 데이터 표시
- 반응형 INFO / GAUGE 홈 화면 위젯
- 위젯 테마, 배경, 투명도 설정
- 새로고침 및 마지막 정상 데이터 캐시
- 세션 만료 시 재로그인
- 숨겨진 개발자 진단 옵션

참고:

- DataPeek은 프리티의 비공식 개인 프로젝트입니다.
- Android/WebView 특성상 백그라운드 서버 갱신에는 제한이 있을 수 있습니다.
